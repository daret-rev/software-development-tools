# triangle

Модуль [`triangle.py`](../triangle.py)

```python
def area(a, h)            # (1)
def perimeter(a, b, c)    # (2)
```

1) Вычисляет площадь треугольника по основанию и высоте.

2) Вычисляет периметр треугольника по трём сторонам.

### Функции

| Функция                           | Описание                                        |
|-----------------------------------|-------------------------------------------------|
| [`area`](#trianglearea)           | вычисляет площадь треугольника по его сторонам  |
| [`perimeter`](#triangleperimeter) | вычисляет периметр треугольника по его сторонам |

---

## triangle.area

```python
def area(a, h)
```

Возвращает площадь треугольника с основанием `a` и высотой `h`, равную `a * h / 2`.

### Параметры

- `a` (`int` или `float`) - длина основания треугольника, `a >= 0`
- `h` (`int` или `float`) - высота, проведённая к основанию `a`, `h >= 0`

### Возвращаемое значение

Площадь треугольника типа `float`.

### Примечание

Функция не проверяет аргументы. Для корректного вычисления необходимы целые или дробные числовые аргументы. Для отрицательных `a` и `h` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import triangle

print(triangle.area(4, 3.2))
```

Вывод:

```text
6.4
```

## triangle.perimeter

```python
def perimeter(a, b, c)
```

Возвращает периметр треугольника со сторонами `a`, `b` и `c`, равный `a + b + c`.

### Параметры

- `a` (`int` или `float`) - первая сторона треугольника, `a >= 0`
- `b` (`int` или `float`) - вторая сторона треугольника, `b >= 0`
- `c` (`int` или `float`) - третья сторона треугольника, `c >= 0`

### Возвращаемое значение

Периметр треугольника. Тип результата - `int`, если все аргументы целые, и `float` в остальных случаях.

### Примечание

Функция не проверяет аргументы, в том числе то, что стороны образуют существующий треугольник (сумма любых двух сторон больше третьей).
Для корректного вычисления необходимы целый или дробные числовые аргументы. Для отрицательных `a`, `b` и `c` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import triangle

print(triangle.perimeter(2, 4, 3.0))
```

Вывод:

```text
9.0
```
