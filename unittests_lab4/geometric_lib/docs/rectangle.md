# rectangle

Модуле [`rectangle.py`](../rectangle.py)

```python
def area(a, b)       # (1)
def perimeter(a, b)  # (2)
```

1) Вычисляет площадь прямоугольника.

2) Вычисляет периметр прямоугольника.

Тип результата - `int`, если все аргументы целые, и `float` в остальных случаях.

### Функции

| Функция                            | Описание                                                   |
|------------------------------------|------------------------------------------------------------|
| [`area`](#rectanglearea)           | вычисляет площадь прямоугольника по его основанию и высоте |
| [`perimeter`](#rectangleperimeter) | вычисляет периметр прямоугольника по его сторонам          |

---

## rectangle.area

```python
def area(a, b)
```

Возвращает площадь прямоугольника с основанием `a` и высотой `b`, равную `a * b`.

### Параметры

- `a` (`int` или `float`) - основание прямоугольника, `a >= 0`
- `b` (`int` или `float`) - высота прямоугольника, `b >= 0`

### Возвращаемое значение

Площадь прямоугольника типа `int` или `float`.

### Примечание

Функция не проверяет аргументы. Для корректного вычисления необходимы целые или дробные числовые аргументы. Для отрицательных `a` и `b` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import rectangle

print(rectangle.area(7, 9))
```

Вывод:

```text
63
```

## rectangle.perimeter

```python
def perimeter(a, b)
```

Возвращает периметр прямоугольника с основанием `a` и высотой `b`, равный `2 * (a + b)`.

### Параметры

- `a` (`int` или `float`) - основание прямоугольника, `a >= 0`
- `b` (`int` или `float`) - высота прямоугольника, `b >= 0`

### Возвращаемое значение

Периметр прямоугольника типа `int` или `float`.

### Примечание

Функция не проверяет аргументы. Для корректного вычисления необходимы целый или дробные числовые аргументы. Для отрицательных `a` и `b` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import rectangle

print(rectangle.perimeter(4, 8))
```

Вывод:

```text
24
```
