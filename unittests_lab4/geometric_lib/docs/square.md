# square

Модуль [`square.py`](../square.py)

```python
def area(a)        # (1)
def perimeter(a)   # (2)
```

1) Вычисляет площадь квадрата.

2) Вычисляет периметр квадрата.

Тип результата - `int`, если аргумент целый, и `float` в остальных случаях.

### Функции

| Функция                         | Описание                                   |
|---------------------------------|--------------------------------------------|
| [`area`](#squarearea)           | вычисляет площадь квадрата по его стороне  |
| [`perimeter`](#squareperimeter) | вычисляет периметр квадрата по его стороне |

---

## square.area

```python
def area(a)
```

Возвращает площадь квадрата со стороной `a`, равную `a * a`.

### Параметры

- `a` (`int` или `float`) - сторона квадрата, `a >= 0`

### Возвращаемое значение

Площадь квадрата типа `int` или `float`.

### Примечание

Функция не проверяет аргумент. Для корректного вычисления необходим целый или дробный числовой аргумент. Для отрицательного `a` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import square

print(square.area(4))
```

Вывод:

```text
16
```

## square.perimeter
