hardwareCountersProfile

internal fun hardwareCountersProfile(basePath: File, argsFile: File, projectState: ProjectState?, processInit: ProcessBuilder? = null): Pair<HardwareCountersProfileResult?, CmakeBuilder.GenerationResult?>

Запускает аналитику аппаратных счетчиков через perf stat

Запускает perf stat -r 5 -x, -e cycles,instructions,branches,branch-misses,cache-misses для собранного бинарника. Результат сохраняет во временный CSV-файл /tmp/stat.csv. После файл парсится и разбирается на пары ключ-значение -- берется значение (первое поле) и ставится в соответсявие имени параметра (третье поле)

Из собранных данных формируется HardwareCountersProfileResult:

  • cycles, instructions, branches, branchMisses, cacheMisses - значения из счетчиков;

  • IPC - instructions / cycles;

  • proportionalMisses - 100 * branchMisses / branches;

Не распознаные счётчики остаются null (в отчёте н/д).

Return

Pair HardwareCountersProfileResult и null при успехе, либо null и GenerationResult.ERROR при ошибке

Parameters

basePath

Корневая директория проекта.

argsFile

Файл с аргументами для тестирования

projectState

ProjectState Информация о проекте

processInit

Конструктор процессов в корне проекта, через который выполняются команды и собирается информация. При получении null создается новый ProcessBuilder с раюбочей дерикторией в корне проекта project.basePath
