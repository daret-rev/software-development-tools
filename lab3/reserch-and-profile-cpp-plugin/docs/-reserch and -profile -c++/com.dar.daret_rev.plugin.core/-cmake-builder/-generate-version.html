GenerateVersion

suspend fun GenerateVersion(processInit: ProcessBuilder? = null): CmakeBuilder.GenerationResult

Генерация отчёта для текущей версии проекта.

Сначала вызывается Start, он готовит среду и инициализирует необходимые файлы. Проверят наличие аргументов для тестирований в reserch/.args.txt или явное их отсутствие. Если их нет возвращает ExitValue.NO_ARGS, чтобы пользователь добавил аргументы.

После выполняеттестирования и мобирает информацию, записывая данные в reserch/RESERCH.md через MarkdownGenerator:

  1. coldAndHotTest: холодный и горячий запуск, время и память;

  2. hardwareCountersProfile: аппаратные счетчики perf stat;

  3. findBottleneck: узкие места perf record&perf report;

  4. sanitizerTests: тестирование TSan и ASan;

При получении ошибки в тесте, завершает выполнение и возвращает ошибку.

Функция блокирующая, поэтому вызывать ее с UI потока нельзя, необходимо переключиться на рабочий поток.

Return

GenerationResult.SUCCESS елси все выполнилось корректно, GenerationResult.ERROR с ExitValue.NO_ARGS если нужно ввести аргументы и GenerationResult.ERROR с ExitValue.ERROR в случае ошибки

Parameters

processInit

Конструктор процессов в корне проекта, через который выполняются команды и собирается информация. При получении null создается новый ProcessBuilder с раюбочей дерикторией в корне проекта project.basePath
