coldAndHotTest

internal fun coldAndHotTest(basePath: File, argsFile: File, projectState: ProjectState?): Pair<ColdAndHotTestsResult?, CmakeBuilder.GenerationResult?>

Запускает холодные и горячие тесты, собирая данные о скорости и памяти

Для тестов запрашивается root доступ для сброса кэша ОС и проводится холодный запуск. Далее 5 горячих без сброса, из них берутся реальное время (E), время в пользовательском режиме (U), время в ядре (S) и пик памяти в КБ (M).

Результаты формируются в структуру ColdAndHotTestsResult:

  • coldTime - E холодного запуска, сж

  • hotTime - минимальное E среди теплых запусков, с;

  • mediumHotTime - медиана E среди теплых запусков, с;

  • cpuLoad - (U + S) / E запуска с минимальным E;

  • maxMemory - M / 1024 того же запуска, МБ;

  • speed - скорость обработки данных, ГБ/с (пока заглушка).

Return

Pair ColdAndHotTestsResult и null при успехе, либо null и GenerationResult.ERROR при ошибке

basePath

Корневая директория проекта.
