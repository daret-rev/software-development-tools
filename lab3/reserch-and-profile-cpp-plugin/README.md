# Reserch-and-profile-cpp

Плагин помогает вести исследования проекта в динамике, создавая профилирование версий по коммитам.
При первом запуске он собирает информацию о системе, создает рабочий каталог и генерирует главный файл исследования.

При последующих запусках главный файл будет дополняться информацией о текущей версии, что позволит отслеживать историю улучшения и планировать оптимизацию.


## Тестирование версии

Тестирование состоит из нескольких секций, собирающих различные данные:

### Время и память

Содержит информацию о:
- Холодном запуске (кэш ОС сбрасывается)
- Горячих запусков (мин. и сред.)
- Загрузке процессора
- Пике памяти
- Скорости (ГБ/c)

### Аппаратные счетчики

Собирает статистику с аппаратных счетчиков процессора:

- Такты
- Выполненные инструкции
- ICP инструкции за такт
- Количество ветвлений
- Количество промахов на ветвлениях
- Доля промахов на ветвлениях
- Промахи кэше

### Профилирование `узких мест` (потерь)

Создает и анализирует профиль исполняемого файла, сохраняя данные о наиболее затратных участках.

### Санитайзеры

Собирает проект под два санитайзера TSan и ASan.

TSan - детектор ошибок многопоточности.
Ищет гонки данных, ошибки блокировок, взаимные блокировки.

ASan - детектор ошибок работы с памятью.
Ищед выходы за границы доступной памяти, использование после удаления или не инициализированной памяти,
использование после уделения, двойное освобождение, утечки памяти.

## Генерация профиля

После сбора данных в тестировании они заносятся в файл исследования под хэшем соответствующего коммита.
