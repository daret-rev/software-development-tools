# circle

Модуль [`circle.py`](../circle.py)

```python
def area(r)        # (1)
def perimeter(r)   # (2)
```

1) Вычисляет площадь круга.

2) Вычисляет длину окружности (периметр круга).

Все функции модуля возвращают значение типа `float`.

### Функции

| Функция                         | Описание                                |
|---------------------------------|-----------------------------------------|
| [`area`](#circlearea)           | вычисляет площадь круга по его радису   |
| [`perimeter`](#circleperimeter) | вычисляет длину окружности по ее радису |

---

## circle.area

```python
def area(r)
```

Возвращает площадь круга радиуса `r`, равную `math.pi * r ** 2`.

### Параметры

- `r` (`int` или `float`) - радиус круга, `r >= 0`

### Возвращаемое значение

Площадь круга типа `float`.

### Примечание

Функция не проверяет аргумент. Для корректного вычисления необходим целый или дробный числовой аргумент. Для отрицательного радиуса `r` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import circle

print(circle.area(9.7))
```

Вывод:

```text
295.5924527762636
```

---

## circle.perimeter

```python
def perimeter(r)
```

Возвращает длину окружности радиуса `r`, равную `2 * math.pi * r`.

### Параметры

- `r` (`int` или `float`) - радиус круга, `r >= 0`

### Возвращаемое значение

Длина окружности типа `float`.

### Примечание

Функция не проверяет аргумент. Для корректного вычисления необходим целый или дробный числовой аргумент. Для отрицательного `r` результат не имеет геометрического смысла.

### Пример

```python
from geometric_lib import circle

print(circle.perimeter(9.7))
```

Вывод:

```text
60.94689747964198
```
